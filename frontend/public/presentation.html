llms.txt

Crawl sites, generate llms.txt, observe trends and more.

What I built

Website analysis

Sitemaps, robots.txt and seed links, scored down to the pages that carry content.

llms.txt generation

llms.txt as the index, llms-full.txt as the page text. Both stored per run.

Schedules

Automated re-crawls on a cadence, run by the worker's scheduler tick.

GitHub publishing

Optional. Connect a repo and a finished run opens a pull request with the file.

Trends

Runs are kept, so you can see what changed on the site and in the artifact.

Opinionated content

A ranked, capped index with an ## Optional section — plus an optional LLM pass.
